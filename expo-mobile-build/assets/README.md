# UniKalkulus Assets

This folder contains the app assets for the Expo mobile build.

## Required Assets

Please add the following images to this folder:

1. **icon.png** - App icon (1024x1024 px)
   - Copy from: `../mobile-build/splash_screen_test/assets/image/icon-unikalkulus.jpg`
   - Resize to 1024x1024 and convert to PNG

2. **adaptive-icon.png** - Android adaptive icon (1024x1024 px)
   - Same as icon.png

3. **splash.png** - Splash screen image (2048x2048 px)
   - Copy from: `../mobile-build/splash_screen_test/assets/image/icon-unikalkulus.jpg`
   - Resize to 2048x2048 and convert to PNG

4. **favicon.png** - Web favicon (48x48 px)
   - Resize icon to 48x48 for web

5. **icon-unikalkulus.png** - Logo for splash screen (512x512 px)
   - Copy from: `../mobile-build/splash_screen_test/assets/image/icon-unikalkulus.jpg`
   - Convert to PNG

## How to Generate Assets

You can use online tools or image editing software to resize and convert the images:
- https://www.iloveimg.com/resize-image
- https://www.iloveimg.com/jpg-to-png
- Or use Photoshop/GIMP

Alternatively, copy the existing Flutter assets and rename them accordingly.
